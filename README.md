# Hentai sub español (plugin de Kino)

Plugin de Kino para ver hentai subtitulado al español de hentaila.com.

- Solo para mayores de 18 años: Kino lo muestra únicamente con el código +18 desbloqueado.
- No pide cuenta ni configuración.
- Permite descargas para ver sin conexión.
- Oculta los títulos de los géneros shota y loli.
- Servidores: MP4Upload y YourUpload.

Requiere Kino 0.9.50 o más nuevo. Para instalarlo: Plugins, botón +, escribe `Nicor1029/kino-hentaila`.
